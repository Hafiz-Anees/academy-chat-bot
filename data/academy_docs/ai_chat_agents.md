# Quantiro AI Chat Agents

## 1. Overview

Quantiro provides **AI chat agents** as part of its AI-based services.

Quantiro AI chat agents can be integrated with different communication channels and existing systems, depending on the available APIs, credentials, and technical requirements.

## 2. Confirmed Integration Capabilities

Quantiro AI chat agents can be integrated with:

* Instagram
* Facebook
* WhatsApp
* Websites/web applications
* Existing systems that provide a usable API
* Existing systems where the required credentials or supported access are available

The exact integration approach depends on the platform, API, credentials, permissions, and technical requirements.

## 3. Existing System Integrations

If a business already uses a software system or platform, Quantiro can assess whether an AI chat agent can integrate with it.

Integration may be possible when the existing system provides:

* An accessible API
* Required authentication credentials
* Appropriate permissions
* A technically usable integration method

The AI agent must not guarantee integration with a specific system until its technical requirements have been reviewed.

## 4. Supported Communication Channels

AI chat agents can be integrated with supported customer communication channels, including:

* Instagram
* Facebook
* WhatsApp
* Websites and web applications

The specific features available through each platform may depend on that platform's API, permissions, policies, and technical limitations.

## 5. Pricing

There is no fixed public price for Quantiro AI chat agents.

Pricing is determined during or after a demo or consultation based on the client's requirements and proposed solution.

The AI agent must not provide estimated, starting, minimum, maximum, package, hourly, or monthly pricing unless explicitly documented in the knowledge base.

## 6. Customer Requirement Gathering

When a potential customer is interested in an AI chat agent, the agent may collect relevant information such as:

* Business name
* Business type
* Current communication process
* Main problem they want to solve
* Desired outcome
* Required communication channels
* Existing software or systems
* Required integrations
* Available APIs or credentials
* Important business workflows
* Other specific requirements

The AI agent should collect only the information relevant to the customer's request.

## 7. Integration Assessment

Before confirming that a specific integration can be implemented, the following should be considered:

1. Which platform or system needs to be integrated?
2. Does it provide an API or another supported integration method?
3. Are the required credentials available?
4. Are the necessary permissions available?
5. What data or actions need to be exchanged?
6. Are there technical or platform-specific limitations?

If these details are unknown, the AI agent should ask for the necessary information rather than making assumptions.

## 8. Demo and Consultation

A general process is:

1. The customer explains their requirements.
2. Quantiro reviews the requirements.
3. A demo or consultation can be conducted.
4. The proposed solution and integration scope are discussed.
5. Pricing is determined based on the requirements and proposed solution.
6. The project proceeds if the customer is interested in purchasing the service.

This process should not be presented as a guaranteed timeline.

## 9. Accuracy and Grounding Rules

The AI chat agent must:

* Never invent features or integrations.
* Never assume that an API exists.
* Never assume that provided credentials are sufficient.
* Never expose, request, or repeat sensitive credentials unnecessarily.
* Never ask customers to send passwords, API secret keys, access tokens, or other sensitive credentials directly in chat unless there is an explicitly approved secure process.
* Never guarantee integration before the technical requirements have been reviewed.
* Never provide unconfirmed pricing.
* Never promise an unconfirmed development timeline.
* Never guarantee business results.
* Clearly distinguish confirmed capabilities from capabilities that require technical verification.
* Ask clarification questions when requirements are unclear.
* State when information is not available instead of guessing.
