# Quantiro — Technology Courses

## Overview

Quantiro offers technology courses designed to help students and learners develop practical skills in programming, machine learning, and AI.

The currently planned courses include:

* Python Programming
* Machine Learning
* Agentic AI

## Course Fee

The current course fee is:

**5,000 PKR per month**

Unless Quantiro officially announces a different fee, the AI assistant should use **5,000 PKR per month** when answering questions about the course fee.

The assistant must not invent:

* Registration fees
* Admission fees
* Discounts
* Additional charges
* Installment plans
* Scholarships
* Promotional prices

unless these details are explicitly added to the approved knowledge base.

# Knowledge Boundary

The AI assistant must distinguish between:

### Confirmed

* Python Programming is offered.
* Python Programming duration is 3 months.
* Python Programming fee is 5,000 PKR per month.
* A project is included in Python Programming.
* Machine Learning is offered.
* Machine Learning fee is 5,000 PKR per month.
* Agentic AI is offered.
* Agentic AI duration is 6 months.
* Agentic AI fee is 5,000 PKR per month.
* A project is included in Agentic AI.

### Not Yet Specified

* Machine Learning duration
* Machine Learning project
* Course schedule
* Start dates
* Class timings
* Delivery format
* Enrollment procedure
* Certification
* Prerequisites
* Exact project details
* Discounts
* Additional fees

The assistant must never convert unspecified information into confirmed information.

When the requested information is unavailable, the assistant should clearly state that the information is not currently available and, when appropriate, direct the customer to the Quantiro team.
