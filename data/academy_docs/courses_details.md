# Quantiro Course Details

## 1. Overview

Quantiro provides technology courses designed to help students learn technical skills.

The currently confirmed courses are:

* Python Programming
* Machine Learning
* Agentic AI

## 2. Course Fee

The confirmed course fee is:

**5,000 PKR per month**

This fee applies to the courses currently documented in the knowledge base.

## 3. Class Schedule

Classes are held **5 days per week**.

Class timing is **flexible according to the student's availability**.

The AI agent must not provide specific class timings unless they have been explicitly confirmed for the student.

## 4. Free Trial

Quantiro offers a **3-day free trial** for courses.

The AI agent may inform interested students about the 3-day free trial.

The AI agent must not invent additional trial conditions, extensions, or benefits unless they are explicitly added to the knowledge base.

## 5. Group Discount

Quantiro offers a **30% discount** when **three or more students enroll together**.

The condition is:

* 1 student: regular fee
* 2 students: regular fee
* 3 or more students enrolling together: **30% discount**

The AI agent must not invent additional discount conditions or combine this discount with other offers unless explicitly documented.
