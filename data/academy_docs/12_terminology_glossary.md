# Common Terms Students Use (Glossary)

Students and parents often use different names for the same courses. All of the terms below refer to courses we already teach at the academy.

**Nazra Quran / Nazra-e-Quran / Nazra / "Quran padhna" / Quran reading** — refers to learning to read the Quran with correct pronunciation. At our academy, this journey starts with the **Noorani Qaida** course (alphabet, pronunciation, joining letters) for beginners, followed by fluent Quran reading practice. If a student can already read Arabic script, they may only need reading practice rather than starting from Qaida — this is assessed during the free trial.

**Qaida / Qaida Sharif** — same as Noorani Qaida, the beginner course covering the Arabic alphabet and basic reading rules.

**Hifz / Hifz-ul-Quran / "Hafiz banna" / Quran yaad karna / memorize Quran** — refers to our Hifz-ul-Quran (Quran memorization) course.

**Tajweed / Tarteel / "Quran sahih parhna" / correct pronunciation rules** — refers to our Tajweed course, focused on the rules of correct Quranic recitation.

**Dua / Duain / Masnoon Dua / daily duas** — refers to our Masnoon Duas course.

**Trial / demo class / free class** — refers to our 3-day free trial.

**Fees / price / kitna paisa** — refers to course pricing (PKR 5,000/month standard fee).
